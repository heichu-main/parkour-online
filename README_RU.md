# Паркур — общий онлайн-сервер

В этой папке лежат игра (`index.html`) и сервер (`server.js`). Сервер раздаёт страницу игры и соединяет всех игроков в одну общую комнату через WebSocket. Комнаты и коды не нужны.

## Загрузка на GitHub
1. Открой https://github.com/new и создай репозиторий, например `parkour-online`.
2. Можно выбрать Public или Private; если Render не видит приватный репозиторий, подключи его в настройках Render.
3. Нажми **Add file → Upload files**.
4. Распакуй архив на компьютере и перетащи **содержимое папки** `parkour-online-server` (файлы `index.html`, `server.js`, `package.json`, `README_RU.md`) на страницу загрузки GitHub.
5. Нажми **Commit changes**.

## Запуск на Render
1. Открой https://render.com/ и войди через GitHub.
2. Нажми **New + → Web Service**.
3. Подключи репозиторий `parkour-online` и нажми **Connect**.
4. В настройках укажи:
   - **Runtime / Language:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance type:** Free для первого теста, если доступен.
5. Нажми **Create Web Service** и дождись статуса **Live**.
6. Открой выданный адрес вида `https://ИМЯ.onrender.com`. Именно эту ссылку отправляй друзьям. Страница сама подключится к `/ws` на том же сервере.

## Проверка
- Открой сайт в двух разных браузерах или на двух устройствах.
- Нажми «Играть» в обоих окнах и проверь, что они видят друг друга.
- Если сервер только что проснулся после простоя, первая загрузка может занять немного времени.

## Важно
- Бесплатный сервер может засыпать после простоя и запускаться с задержкой; это ограничение хостинга.
- Это базовый общий сервер для обмена состоянием игроков, а не авторитетный физический сервер. На нестабильной сети столкновения могут расходиться.
- Не размещай в публичном репозитории личные данные, пароли или токены.
