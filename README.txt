ПАРКУР — PWA-пакет для Render

Файлы:
- index.html — игра с подключённым PWA и попыткой включить fullscreen при нажатии «Играть»
- manifest.webmanifest — настройки установки приложения и полноэкранного режима
- sw.js — Service Worker (кэш оболочки приложения)
- icons/ — иконки приложения

КАК ЗАГРУЗИТЬ НА RENDER:
1. Распакуй архив.
2. Загрузи ВСЁ содержимое папки parkur_pwa в корень репозитория сайта (рядом с index.html, не внутрь дополнительной папки).
3. Сделай commit/push — Render обновит Static Site.
4. Открой сайт по HTTPS.
5. На Android: меню браузера → «Установить приложение» / «Добавить на главный экран».
6. На iPhone: Safari → Поделиться → «На экран Домой».

ВАЖНО:
- Браузер не разрешает сайту включать fullscreen автоматически при простом открытии страницы.
- В игре fullscreen запрашивается после нажатия кнопки «Играть» (если браузер поддерживает API).
- На iPhone обычный Safari не предоставляет стандартный Fullscreen API для всей страницы; режим без адресной строки работает после добавления на экран «Домой».
- Для PWA нужен HTTPS (Render его предоставляет).
- Если сайт уже имел Service Worker, проверь, чтобы старый sw.js не конфликтовал.
